# 0002: The product is called Heresay

Date: 2026-09-28

## Decided

- **Name: Heresay.** Read it as "Here, say it"; hear it as *hearsay*, which the product turns
  into firsthand word from users. Chosen over about 150 candidates (Tamil, Hindi, historical
  petition traditions, plain English, puns).
- **Wordmark:** lowercase, serif, with "say" set in the accent: here*say*.
- **Vocabulary (dashboard):** Heard (open), Sustained (accepted), Overruled (declined, with a
  ruling), Case closed (fixed). A decline reason is a *ruling*; an accepted report handed to an
  agent is a *brief*. The widget inside host apps uses plain words.
- **Voice:** plain first, pun second. No puns in errors or in declines.

## Availability (checked 2026-09-28)

Free: `heresay.dev` (registry RDAP), npm `heresay` and the `@heresay` scope, GitHub `heresay-dev`
and `heresayhq`. Taken: `heresay.com`, `heresay.app`, GitHub `heresay`. Other small, unrelated
apps use the name (a travel map, an ETH Zurich crowdsourcing app, a voice chat site).

## Open

- **Trademark.** "Heresay" sounds identical to "Hearsay", and Yext owns the live US mark
  HEARSAY SOCIAL (reg. 4236941, SaaS for marketing, sales and compliance). Sound-alike marks
  count, so get a trademark opinion before launch.
- Logo direction: Seal, Ear or Bell (`docs/brand/heresay-brand-plan.html`).
