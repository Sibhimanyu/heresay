Technical details
Buttonpublic/sdk.js. No dependencies, shadow DOM, text/plain POSTs (no preflight), random device id in localStorage.
MailroomOne Cloud Function on /v1/*. Key + Origin check. Rate limits: device 5/10 min and 20/day, IP 30/hour, key 500/day.
CabinetFirestore. projects/{p}/reports and projects/{p}/tasks; only accept writes tasks, in one transaction. No direct client access.
DeskStatic dashboard on Firebase Hosting + Firebase Auth, same API.
npm packageNot needed: the script tag works in any site. Add later for version pinning or no-third-party-script policies.
